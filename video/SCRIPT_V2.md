## Accuracy and production notes

- **The numerical gap is conditional.** A gap of 3.02 prevents the ordering from reversing if every score changes by less than 1.51. The paper measures that positive gap on the M4 after deployment rounding; it does not prove a universal bound on rounding on all laptops. The recorded batch tests support the tested combinations, not every possible batch composition. Keep the word “if” in N15 and both inequality labels in shot 6.
- **The proof has a boundary.** Every reference view must belong to the checked tables, and the reference procedures must compute the intended function. Those facts about the runtime are ordinary code obligations, not a completed Lean proof of the whole application. N18 is the required spoken limitation; it also prevents the algebra sequence from implying an end-to-end proof of problem translation.
- **Dialogue training is more than imitation.** N21 separates the original model’s good replies from the original model teaching the adapted model on generated replies. It must not become a claim that on-policy distillation merely filters the adapted model's own successful answers. The source recipe also includes supervised dialogues, and keeps arithmetic rows in every stage. GRPO rewards used an exact-code stand-in for the sheet; they were not browser model runs. Fresh GSM8K evaluation also used that stand-in, so the reported loss concerns dialogue reasoning with exact execution supplied.
